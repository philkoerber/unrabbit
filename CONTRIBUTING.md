# Contributing

Unrabbit is early and intentionally small. An issue with a concrete use case or a focused pull request is welcome. For larger changes, start with an issue so we can agree on the direction.

- Preserve wheel/button navigation and the minimal, dark interface.
- Keep device code independent of any personal VM, account or development machine.
- Distinguish emulator results, real hardware results and planned integrations.
- Keep tests focused on behavior. Run the checks in the [development guide](docs/DEVELOPMENT.md#build) before opening a pull request.
- Use synthetic setup data and screenshots. Do not commit credentials, private keys or device state.

Original contributions are made under the project's [MIT license](LICENSE). Preserve third-party license notices.
